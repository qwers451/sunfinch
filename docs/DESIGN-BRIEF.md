# SunFinch: бриф для дизайна

Документ для дизайна в Claude Design. Здесь описано всё, что делает браузер: что уже работает, что запланировано, где каждая вещь находится в окне, какие у неё состояния и тексты. Решения по устройству (что где находится) уже приняты, их помечаем **[решено]**; всё остальное — поле для дизайна.

## 1. Продукт

**SunFinch** — настольный браузер для Windows на движке Firefox (ESR 153). Пользователь работает с большим количеством вкладок и задач, поэтому браузер помогает раскладывать их по пространствам, быстро заглядывать в ссылки, держать под рукой заметки и спрашивать локального Claude о текущей странице.

- Платформа: Windows 10/11, позже возможно macOS/Linux.
- Язык интерфейса: **русский по умолчанию**, английский как исходный. Русские строки длиннее английских на 20–40 %, макеты должны это выдерживать.
- Темы: светлая и тёмная, следуют системе.
- Нельзя использовать имя «Firefox» и логотипы Mozilla.

## 2. Бренд

- **Название:** SunFinch («солнечный вьюрок»).
- **Логотип:** геометрическая птица из плоских фигур в полёте, смотрит вправо (`branding/source/sunfinch-logo.webp`, 1430×1100, прозрачный фон).
- **Палитра логотипа:**

| Цвет | HEX | Где сейчас |
|---|---|---|
| Жёлтый | `#FFB300` (светлее — `#FFD020`) | Акцент в тёмной теме |
| Оранжевый | `#FF5F00` | Акцент в светлой теме |
| Индиго | `#4433E0` | Цвет фокуса |
| Тёмно-синий | `#11132F` | Контуры на логотипе |
| Бирюзовый | `#00ADA0` | Пока не используется |

- **Настроение:** тёплое, лёгкое, не «хакерское». Яркие цвета логотипа — акцентами, основа интерфейса спокойная.
- **Нужно от дизайна:**
  - упрощённая иконка для 16–32 px (на 16 px птица сейчас превращается в цветное пятно; идея — голова с клювом и глазом);
  - иконка приложения для Windows (ICO: 16, 24, 32, 48, 64, 128, 256);
  - вариант логотипа для окна «О программе» и установщика.

## 3. Окно браузера: общая раскладка **[решено]**

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ [Пространство 1][Работа][Учёба][+]  ← →  ⟳  [ адресная строка        ] 📱 📷 💬 📝 ≡ │  ← панель инструментов
├────────────┬─────────────────────────────────────────────────┬───────────────┤
│ Вкладки    │                                                 │ Claude        │
│ ── основные│              страница                           │ (панель       │
│ ▸ Почта    │                                                 │  справа,      │
│ ▸ Таск-трек│                                                 │  открывается  │
│ ──────────-│                                                 │  кнопкой 💬)  │
│ ▸ Статья   │                                                 │               │
│ ▸ Поиск    │                                                 │               │
│ доп. вклад.│                                                 │               │
├────────────┤                                                 │               │
│ ⚙ 🔖 🕘     │                                                 │               │
└────────────┴─────────────────────────────────────────────────┴───────────────┘
                                              ┌────────────┐
                                              │ Заметки    │ ← всплывающее окно под кнопкой 📝
                                              └────────────┘
```

- **Сверху** — одна панель инструментов: переключатель пространств (в начале), навигация, адресная строка, наши кнопки (в конце), меню.
- **Слева** — вертикальный список вкладок текущего пространства. Это штатная боковая панель Firefox: её можно свернуть до иконок, внизу кнопки инструментов (закладки, история и т. п.).
- **Справа** — панель Claude (по кнопке).
- **Поверх страницы** — Glance и окно заметок.
- Отдельной полосы горизонтальных вкладок нет.

## 4. Функции

### 4.1. Вертикальные вкладки — работает

Штатные вертикальные вкладки Firefox, включены по умолчанию. Мы меняем только вид.

- Состояния вкладки: обычная, наведение, выбранная, загрузка, звук, закреплённая (pin), в группе вкладок (группы — штатная функция Firefox с цветной меткой).
- Сейчас выбранная вкладка отмечена полоской акцентного цвета 3 px слева.
- Свёрнутый режим — только фавиконки.
- **Для дизайна:** вид вкладки в обоих режимах, выбранная/наведённая, отступы, разделитель секций (см. 4.2).

### 4.2. Пространства — работает

Пространство — отдельный набор вкладок для задачи или контекста (Работа, Учёба, Личное). Видны только вкладки текущего пространства.

**Переключатель [решено]:** ряд кнопок в начале верхней панели. Горячих клавиш нет.
- Кнопка пространства: название, у активного — подчёркивание цветом пространства и жирный текст.
- Кнопка «+» — новое пространство: сейчас системный диалог «Новое пространство / Название:», по умолчанию «Пространство N».
- Правый клик по кнопке: «Переименовать…», «Удалить пространство (вкладки перейдут в первое)». Последнее пространство удалить нельзя.
- У пространства есть цвет: подбирается автоматически из палитры (`#FF5F00`, `#4433E0`, `#00ADA0`, `#FFB300`, `#E0338A`, `#5B8C00`). Запланированы иконка (эмодзи или значок) и выбор цвета пользователем.
- Названия бывают длинными. Сейчас кнопка обрезается многоточием после 14 em. Когда пространств много (8+), нужно решение: прокрутка, сжатие до иконок или меню «ещё».

**Два вида вкладок [решено]:**
- **Основные** — постоянные вкладки пространства (почта, трекер). Живут, пока их не закроют, и переживают перезапуск браузера.
- **Дополнительные** — всё временное. Закрываются при выходе из браузера (после сбоя не закрываются). Закрытые можно вернуть из «Недавно закрытых».
- В списке слева сначала идут основные, под разделителем — дополнительные. Сейчас разделитель — тонкая линия.
- Новая вкладка всегда дополнительная. Сделать её основной можно через контекстное меню вкладки: «Сделать основной (останется после перезапуска)» / «Сделать дополнительной (закроется при выходе)». Запланировано перетаскивание через разделитель.
- «Переместить в пространство ▸» — подменю с остальными пространствами.

**Поведение, которое стоит отразить в дизайне:**
- Ссылка, открытая из вкладки, попадает в то же пространство.
- Пустое пространство при переключении получает новую вкладку.
- Если выбрать вкладку другого пространства (через поиск или список всех вкладок), браузер переключается на её пространство.

**Для дизайна:**
- переключатель (активное, наведение, перетаскивание порядка — запланировано, много пространств, длинные названия);
- диалоги создания и переименования (вместо системного окна): название, цвет, иконка;
- заголовки или разделитель секций «основные / дополнительные» в списке вкладок;
- как показать, что вкладка основная (значок? отдельный фон?);
- запланировано: у пространства может быть свой контейнер — отдельные куки и логины. Нужен значок «изолированное пространство».

### 4.3. Заметки — работает

Быстрый блокнот под рукой.

- **[решено]** Одна общая заметка на все пространства и окна.
- **[решено]** Кнопка 📝 справа вверху. Открывает отдельное всплывающее окно со стрелкой к кнопке, сейчас шириной 26 em, с текстовым полем примерно на 18 строк (высоту можно тянуть).
- **[решено]** Окно не закрывается, пока работаешь со страницей, переключаешь вкладки и пространства, жмёшь Esc. Закрывается только повторным нажатием кнопки; кнопка в это время «нажата».
- Сохраняется автоматически, через полсекунды после ввода.
- Сейчас внутри: заголовок «Заметки», поле с подсказкой «Пишите что угодно…».
- **Для дизайна:** окно, состояние кнопки, пустое и заполненное поле. Опционально: признак «сохранено», размер окна. Сейчас это обычный текст; форматирование (списки, чекбоксы) — открытый вопрос.

### 4.4. Glance — работает

Быстрый просмотр ссылки, не уходя со страницы.

- **[решено]** Alt+клик по ссылке (модификатор настраивается: Alt, Shift, Ctrl, Win).
- Ссылка открывается в окне поверх текущей страницы. Сейчас окно занимает всё, кроме отступов 4 % сверху и снизу и 8 % по бокам; скругление 8 px, тень; страница под ним затемнена на 45 %.
- Кнопки в правом верхнем углу окна: «Открыть вкладкой» (страница становится обычной вкладкой текущего пространства) и «Закрыть» (подсказка «Закрыть (Esc)»).
- Закрыть: Esc, клик по затемнению, кнопка, переход на другую вкладку.
- Внутри — полноценная страница: можно ходить по ссылкам, логиниться, скачивать.
- **Для дизайна:**
  - рамка окна и затемнение;
  - панель кнопок; возможно, адрес и заголовок открытой страницы, индикатор загрузки, кнопка «Назад» внутри Glance;
  - анимация появления (из точки клика?).

### 4.5. Клиент Claude — работает

Чат с локальным Claude (Claude Code на компьютере пользователя, по его подписке) о текущей странице.

- **[решено]** Панель справа от страницы, открывается кнопкой 💬 в панели инструментов. Ширина 380 px по умолчанию, тянется разделителем (260 px — 60 % окна).
- Сейчас в панели:
  - шапка: «Claude» и кнопка «Новый чат»;
  - строка контекста: чекбокс «Учитывать страницу:» и название текущей страницы (обновляется при смене вкладки);
  - лента сообщений: вопрос пользователя — пузырь справа, ответ — обычный текст на всю ширину;
  - пока ответ не начался — «…», дальше ответ появляется по мере генерации;
  - поле ввода (3 строки, «Спросите об этой странице…»), кнопки «Отправить» (основная) и «Остановить» (вместо неё во время ответа). Enter отправляет, Shift+Enter переносит строку.
- **Как работает контекст:** при первом вопросе Claude получает текст страницы (или только выделенный фрагмент, если что-то выделено). Уточняющие вопросы продолжают тот же диалог. Если пользователь перешёл на другую страницу или поменял выделение, новый текст уходит вместе со следующим вопросом.
- Ошибки — красным текстом под вопросом. Тексты: «Claude Code не найден. Установите его или укажите путь к claude.exe в about:config: sunfinch.claude.path», «Claude не ответил: {сообщение}», «Остановлено».
- **Ограничение безопасности:** ответ модели показывается только как текст. Markdown (заголовки, списки, код) можно рисовать, но это будет безопасный разбор без HTML; ссылки из ответа не кликабельны или открываются только после подтверждения.
- **Для дизайна:**
  - панель целиком в двух темах;
  - пузыри и ответы, блоки кода в ответах;
  - показ контекста (страница или выделение, как отключить);
  - пустое состояние с подсказками («Кратко перескажи», «Найди даты и цифры»…);
  - ошибки и отсутствие Claude Code;
  - быстрые действия над выделенным текстом (запланировано: «Спросить Claude» в контекстном меню страницы);
  - история чатов — открытый вопрос (сейчас диалог живёт, пока открыта панель).

### 4.6. Мобильная версия — работает

Кнопка 📱 показывает текущую страницу как на телефоне.

- Включает встроенный адаптивный режим инструментов разработчика: экран 390×844, плотность 3×, тач, iPhone. Страница перезагружается с мобильным User-Agent.
- Кнопка-переключатель: «нажата», пока режим включён на текущей вкладке.
- Вид самого режима (рамка устройства, панель размеров) штатный. Дизайну нужны только кнопка и её состояния; можно предложить, нужна ли эта панель размеров вообще.

### 4.7. Скриншот — работает

Кнопка 📷 делает снимок в один клик.

- Клик — видимая часть страницы, Shift+клик — вся страница целиком.
- По умолчанию снимок сразу копируется в буфер и сохраняется в «Загрузки» (имя «Screenshot ДАТА at ВРЕМЯ Заголовок.png»). Появляется подсказка «Скопировано» у кнопки и анимация панели загрузок.
- Настройка (пока только в about:config): «файл», «буфер» или «оба».
- **Для дизайна:** иконка, подтверждение (вспышка, миниатюра снимка в углу?), как подсказать про Shift.

### 4.8. Split View — запланировано

В Firefox 153 уже есть штатный Split View: две вкладки рядом с разделителем, активная половина выделена рамкой. Мы встраиваем его в пространства: обе половины в одном пространстве, порядок с Glance — Glance открывается поверх всего разделённого вида.

- **Для дизайна:** как запустить (контекстное меню вкладки, перетаскивание вкладки к краю страницы, кнопка), разделитель, активная половина, как пара выглядит в списке вкладок слева, закрытие одной половины.

### 4.9. Страница истории — запланировано, нужен макет до разработки

Новая страница вместо штатной истории (открывается из меню и сочетанием Ctrl+H).

- Поиск по заголовку и адресу.
- Группировка по датам (сегодня, вчера, неделя, месяц, раньше) и по сайтам.
- Фильтры: диапазон дат, конкретный сайт.
- Запись: фавиконка, заголовок, адрес, время, по желанию — превью страницы. Превью снимаются при посещении; это место на диске и вопрос приватности, поэтому в настройках есть «показывать превью» и «очистить превью».
- Действия: открыть, открыть в новой вкладке или в пространстве, удалить запись, «забыть сайт» (удалить всё о сайте).
- История бывает на сотни тысяч записей: список бесконечный, подгружается при прокрутке.
- **Для дизайна:**
  - страница целиком: список и/или сетка с превью;
  - вид «по сайтам»;
  - пустой поиск, ничего не найдено, история пуста;
  - подтверждение удаления.

### 4.10. Настройки SunFinch — предложение

Сейчас наши настройки доступны только через about:config. Нужен раздел «SunFinch» в штатных настройках (about:preferences):
- Glance: модификатор клика.
- Скриншот: куда сохранять (файл, буфер, оба).
- Claude: путь к Claude Code, модель, сколько текста страницы отправлять.
- Пространства: поведение дополнительных вкладок (закрывать при выходе — да/нет?).
- История: превью да/нет, очистить превью.
- **Для дизайна:** раздел в стиле штатных настроек Firefox.

### 4.11. Прочее брендированное

- Окно «О программе» (имя, версия 0.1.0, логотип).
- Установщик Windows (NSIS): фон, логотип.
- **Новая вкладка — своя страница SunFinch [решено].** Нужен макет: поиск (Google), часто посещаемые сайты и/или закладки, связь с пространствами (например, основные вкладки текущего пространства), быстрый доступ к заметкам и Claude. Без рекламы и новостных лент. Она же — домашняя страница.
- Экрана приветствия при первом запуске сейчас нет. Возможно, понадобится свой, с объяснением пространств и Glance.

## 5. Ограничения платформы

- Интерфейс браузера — XUL/HTML внутри Firefox. Стили — CSS (переменные, `light-dark()`, `color-mix()`); шрифт системный (Segoe UI Variable на Windows 11).
- Иконки панели инструментов — **SVG 16×16, одноцветные** (`fill="context-fill"`): цвет подставляется темой, поэтому градиенты и многоцветность в них невозможны. Цветными могут быть фавиконки, логотип и иллюстрации.
- Кнопки нашей панели инструментов пользователь может переставлять и убирать (штатная настройка панели).
- Всплывающие окна (заметки, меню) — штатные панели Firefox со стрелкой к кнопке.
- Пользователи могут ставить темы Firefox (lightweight themes) — интерфейс должен оставаться читаемым с чужими цветами панелей.
- Доступность: всё с клавиатуры, видимый фокус, контраст WCAG AA, режим высокой контрастности Windows.

## 6. Что ждём от дизайна

1. **Токены:** цвета (светлая/тёмная), акценты, цвета пространств, радиусы, тени, отступы, типографика — чтобы перенести в CSS-переменные.
2. **Иконки** 16×16 SVG одним цветом: пространство (запасная), добавить пространство, заметки, Claude, мобильная версия, скриншот, Glance «открыть вкладкой», «основная вкладка», изолированное пространство.
3. **Иконка приложения** и упрощённая птица для 16–32 px.
4. **Макеты экранов** в светлой и тёмной теме:
   - главное окно со всеми элементами (несколько пространств, основные и дополнительные вкладки);
   - открытые заметки;
   - Glance поверх страницы;
   - панель Claude: пустая, с диалогом, с ошибкой;
   - диалог нового пространства;
   - контекстное меню вкладки;
   - страница истории;
   - Split View (позже).
5. **Состояния:** наведение, нажатие, фокус, выключено, «нажата» (для кнопок-переключателей).

**Приоритет:** главное окно и токены → иконки → Claude и заметки → Glance → история → Split View → настройки и прочее.
