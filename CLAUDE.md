# SunFinch

Форк Firefox ESR 153, собирается через surfer (форк Gluon). План, решения и этапы — в `docs/PLAN.md`. Прочитай его перед работой.

## Правила

- Код SunFinch — в отдельных файлах `src/browser/components/sunfinch/`. Патчи к файлам Firefox — только минимальные «крючки» (подключение скриптов, регистрация в `jar.mn`/`moz.build`, prefs). Каждый лишний патч дорожает при ежегодном ребейзе на новый ESR.
- `engine/` — скачанные исходники Firefox. Не коммитить. Правки в них переносятся в `src/` через `surfer export`.
- Код окна браузера работает в родительском процессе. Страницы — в content-процессах. Всё, что видит содержимое страницы (клики, текст, размер), доходит до родителя через JSWindowActor.
- Файлы — через `IOUtils`/`PathUtils`, не `FileUtils`/`OS.File`. Крупные данные — JSON в профиле, не prefs.
- Текст веб-страниц — недоверенный ввод. В клиент Claude он уходит через stdin, CLI запускается без инструментов (`--tools ""`).
- Без «Firefox» и логотипов Mozilla в брендинге и строках интерфейса.
- Тексты интерфейса — через Fluent (`.ftl`). Исходные строки en-US (так устроена сборка Firefox), русский — локализация.

## Окружение (Windows)

- Репозиторий: `E:\dev\sunfinch`. Пути без кириллицы и пробелов.
- `MOZBUILD_STATE_PATH=E:\mozbuild`.
- Первая сборка: `surfer download` → `surfer bootstrap` → `surfer import` → `surfer build` → `surfer run`.
