# SunFinch

Браузер на базе Firefox ESR со своими фичами: вертикальные вкладки и пространства, split view, Glance (мини-окна для ссылок), боковая панель с локальным Claude, быстрые заметки, кнопки «мобильная версия» и «скриншот», новая страница истории.

Статус: планирование. Подробный план и обоснование решений — в [docs/PLAN.md](docs/PLAN.md).

## Стек

- Firefox ESR 153
- [surfer](https://github.com/zen-browser/surfer) — сборщик форков Firefox (форк Gluon)
